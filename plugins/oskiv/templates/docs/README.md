# Docs

Start here. Reading order:

1. `product/`: what the system must do. The PRD wins any disagreement.
2. `architecture/`: how it's built.
3. `decisions/`: why significant choices were made. Records are dated and never rewritten; a new
   record supersedes an old one.
4. `research/`: dated findings (`YYYY-MM-DD-slug.md`), immutable once filed.

Spec pages (`product/`, `architecture/`) are edited in place. Research and decisions are history.
